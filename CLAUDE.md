# TrafficLab — инструкции для Claude

TrafficLab — платформа обучения и операционной работы арбитражной команды (медиабаинг). Ученик проходит уроки, сдаёт ДЗ, растёт по уровню доверия (Trust Level), получает доступ к офферам, тестам, аккаунтам, картам и креативам и ведёт дневник результатов. Команда (кураторы, тимлиды, админы) проверяет ДЗ, отвечает на тикеты и заявки, одобряет тесты и предложения офферов.

Монорепозиторий: `backend/` (FastAPI + PostgreSQL) и `frontend/` (React + Vite + TypeScript). Всё поднимается через `docker compose up`.

## Обязательно прочитать перед работой

| Файл | Когда |
| --- | --- |
| `.claude/rules/architecture.md` | всегда: структура репо, слои, кто чем владеет |
| `.claude/rules/business-logic.md` | любая работа с доменом: роли, Trust Level, статусы, права |
| `.claude/rules/api-contract.md` | любой эндпоинт или вызов API — контракт бэка и фронта |
| `.claude/rules/backend.md` | код в `backend/` |
| `.claude/rules/frontend.md` | код в `frontend/` |
| `.claude/rules/testing.md` | перед тем как считать задачу готовой |
| `.claude/rules/git.md` | коммиты и границы файлов при параллельной работе |

## Главные правила

1. **Бизнес-правила проверяются на бэкенде.** Фронт только скрывает недоступное; любое ограничение (роль, Trust Level, статус) обязано быть в сервисном слое бэка и покрыто тестом.
2. **Контракт API — источник истины.** Меняешь форму запроса или ответа — сначала обнови `.claude/rules/api-contract.md`, затем бэк, затем фронт.
3. **Модели и миграции общие.** Новая колонка или таблица — только через новую Alembic-миграцию, никогда не правь применённые миграции.
4. **Пиши в своих границах.** При параллельной работе каждый агент меняет только свои модули (см. `git.md`). Общие файлы (`app/main.py`, `app/models/*`, `src/App.tsx`, `src/api/types.ts`) меняются только координатором.
5. **Язык интерфейса — русский.** Тексты ошибок API для пользователя — на русском (`detail`), имена в коде — на английском.
6. **Готово = тесты зелёные + линтер чистый.** `make test` и `make lint` в корне.

## Быстрые команды

```bash
cp .env.example .env
docker compose up --build          # http://localhost:8080 (фронт + /api), http://localhost:8080/api/docs
docker compose exec backend python -m app.seed --demo   # стартовый контент и демо-пользователи
make test                          # все тесты (бэк в docker-compose.test.yml)
```

Без Docker: см. `docs/local-dev.md`.
